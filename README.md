# Пиксельные гонки

**Игрок ведёт машину по трассе (вид сверху), объезжая конусы и другие машины, и старается как можно быстрее доехать до финиша двух уровней.**

## Как играть

| Клавиша | Действие |
|---|---|
| ↑ / W | газ |
| ↓ / S | тормоз |
| ← → / A D | руль |
| Space | нитро (ускорение на 1.5 с, перезарядка 5 с) |
| P | пауза / продолжить |
| Enter | следующий уровень после финиша |
| R | заново после аварии / после победы |
| M | вернуться в гараж после аварии / после победы |

Перед заездом открывается **гараж**: ←→ или мышью выбери машину, Enter или «В ГОНКУ» — старт.
Пока все машины бесплатные, выбор запоминается в браузере.

- **Уровень 1 — Загородное шоссе:** конусы и попутные машины.
- **Уровень 2 — Пустынная трасса:** быстрее, препятствий больше, в левой полосе едет встречка.
- **Фаза 2:** через **15 секунд игры** (время пройденных уровней + текущего, без пауз) наступает вечер:
  трасса темнеет, препятствий на 40% больше, предел скорости +20%, встречка занимает ещё одну полосу.
  Фаза 2 действует до конца забега. Слева показан отсчёт до неё.
- Удар — **−1 жизнь** и резкая потеря скорости. Жизней 3 на уровень.
- Справа — полоса прогресса до финиша, слева — время и рекорд уровня за сессию.

Трасса, конусы и машины соперников рисуются прямо в коде (`src/game/pixelArt.ts`).
Спрайты машин игрока лежат в `src/assets/cars/`: `*_top.png` — вид сверху для гонки, `*_select.png` — вид 3/4 для гаража.
Список машин — `src/game/cars.ts`, гараж — `src/game/ShopScene.ts`.
Параметры уровней — в `src/game/levels.ts`, параметры машины — константы в начале `src/game/GameScene.ts`.

# Game Dev Starter

Стартовый проект для курса **«Проектирование и разработка игровых приложений»**.

Стек: **TypeScript + Phaser + Vite + GitHub Pages**.

Проект специально маленький: на экране есть только управляемый квадрат, цель и счёт. Это не готовая игра. Это каркас, который нужно превратить в **собственный индивидуальный проект**.

Задание первой практики и домашней работы: [`ASSIGNMENT_01.md`](./ASSIGNMENT_01.md).

## 1. Что нужно установить

- **Node.js 22 LTS** (или Node.js >= 20.19)
- **Git**
- **VS Code** или другая IDE
- аккаунт **GitHub**

Проверка:

```bash
node --version
npm --version
git --version
```

## 2. Первый запуск

```bash
npm install
npm run dev
```

Vite напечатает адрес локального сервера. Обычно это:

```text
http://localhost:5173/
```

Открой его в браузере.

## 3. Что менять в первую очередь

Главный файл для первой практики:

```text
src/game/GameScene.ts
```

Начинай с маленьких изменений:

1. измени поведение игрока;
2. добавь одно игровое действие;
3. добавь реакцию игры;
4. добавь цель или результат;
5. добавь препятствие / риск / условие поражения;
6. добавь Restart.

**Не начинай с меню, магазина, красивой графики и архитектуры на 30 файлов.**

## 4. Проверка production build

Перед публикацией:

```bash
npm run build
```

Если команда завершилась без ошибок, итоговая версия находится в папке `dist/`.

Её можно проверить локально:

```bash
npm run preview
```

## 5. Публикация на GitHub Pages

В репозитории уже есть workflow:

```text
.github/workflows/deploy.yml
```

После push в ветку `main` GitHub автоматически собирает проект.

Для первого включения Pages:

1. открой репозиторий на GitHub;
2. **Settings → Pages**;
3. в **Build and deployment → Source** выбери **GitHub Actions**;
4. открой вкладку **Actions** и дождись успешного `Deploy to GitHub Pages`;
5. ссылка на игру появится в deployment и в разделе Pages.

## 6. Структура проекта

```text
.
├── .github/workflows/deploy.yml   # автоматическая публикация
├── src/
│   ├── game/
│   │   ├── config.ts              # конфигурация Phaser
│   │   └── GameScene.ts           # основная стартовая сцена

│   └── style.css                  # страница вокруг canvas

├── index.html
├── package.json
├── tsconfig.json
└── vite.config.ts
```
